# `1_to_1_*` — поле из отдельной таблицы

Поля, хранимые в отдельной таблице (один-к-одному): `1_to_1_text`,
`1_to_1_textarea`, `1_to_1_wysiwyg`, `1_to_1_checkbox`, `1_to_1_switch`,
`1_to_1_select_values`. Бэкенд: `lib/CRM/form/get_values.py` (чтение),
`lib/CRM/form/save_form.py:update_1_to_1` (запись).

## Атрибуты

| Атрибут | Смысл |
|---|---|
| `type` | один из `1_to_1_*` |
| `name` | имя поля |
| `save_table` | отдельная таблица (обязательно) |
| `foreign_key` | колонка связи в `save_table` (на `form.id`, обязательно) |
| `db_name` | колонка значения внутри `save_table` (по умолчанию = `name`) |
| `read_only`, `permissions` | права |

## Примеры

```python
{'description': 'Таблица размеров', 'type': '1_to_1_wysiwyg',
 'save_table': 'category_sizes', 'foreign_key': 'id',
 'name': 'size_table', 'db_name': 'body'}

{'description': 'Опция', 'type': '1_to_1_checkbox',
 'save_table': 'category_options', 'foreign_key': 'id',
 'name': 'opt_germes', 'db_name': 'opt_germes'}

{'description': 'Произвольный выбор', 'type': '1_to_1_select_values',
 'save_table': 'category_options', 'foreign_key': 'id',
 'name': 'sel', 'db_name': 'sel'}
```

## Особенности

- Значение читается из `save_table WHERE foreign_key = form.id`.
- Сохранение — через `replace=1` (`update_1_to_1`), после сохранения основной
  записи.
- Несколько `1_to_1_*` полей могут делить одну `save_table` (разные `db_name`) —
  как в примере с `category_options`.
- Обязательны `save_table` и `foreign_key`: иначе ошибка в `get_values`.
- `type` в `get_values` определяется как `startswith('1_to_1_')`.

## Разделение по таблицам

Если у карточки много «тяжёлых» полей, их можно вынести в отдельную таблицу
через `1_to_1_*` — основная запись остаётся лёгкой.
