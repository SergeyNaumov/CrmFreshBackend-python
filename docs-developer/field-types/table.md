# `table` — таблица

Вывод произвольной таблицы (заголовки + данные) с возможностью сортировки.
Фронт: `src/components/fields/table.vue`.

## Атрибуты

| Атрибут | Смысл |
|---|---|
| `name` | имя поля |
| `table` | объект `{'headers': [...], 'data': [[...], ...]}` |
| `sort` | включить сортировку по клику на заголовок |
| `sort_desc` | сортировка по убыванию по умолчанию |

`headers[]`: `{'h': 'Заголовок', 'tooltip': 'подсказка'}`.
`data`: список строк (списки ячеек).

## Пример

```python
{
  'description': 'Статистика продаж',
  'type': 'table',
  'name': 'sales_stat',
  'sort': 1,
  'table': {
     'headers': [
         {'h': 'Месяц'},
         {'h': 'Сумма', 'tooltip': 'без НДС'},
     ],
     'data': [
         ['Январь', '100 000'],
         ['Февраль', '120 000'],
     ],
  },
}
```

## Особенности

- Данные обычно формируются в `before_code`/`code` или приходят из
  `field['table']` (его может наполнять бэкенд).
- Используется внутри [`accordion`](accordion.md) как вложенный блок.
