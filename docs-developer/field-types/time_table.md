# `time_table` — расписание

Календарь/расписание с добавлением событий на интервалы. Фронт:
`src/components/fields/time_table.vue`.

## Атрибуты

| Атрибут | Смысл |
|---|---|
| `description`, `name` | базовые |
| `interval_minutes` | шаг сетки календаря в минутах |
| `interval_count` | количество интервалов |
| `first_interval` | первый интервал |
| `form_event_name` | заголовок формы добавления события |
| `value` | выбранная дата |

## Пример

```python
{
  'description': 'Расписание',
  'type': 'time_table',
  'name': 'schedule',
  'interval_minutes': 30,
  'interval_count': 12,
  'form_event_name': 'Добавить запись в расписание',
}
```

## Особенности

- Отображается только для существующих записей (`form.id`).
- События календаря приходят с бэка (поле/запрос формируется в конфиге).
- Редкий тип — смотрите сам компонент при интеграции.
