# `select_values` — выбор из списка

Выпадающий список с фиксированными вариантами `values`.

## Атрибуты

| Атрибут | Смысл |
|---|---|
| `values` | список `[{'v': значение, 'd': подпись}]` |
| `multilpe` | мультивыбор (внимание: именно `multilpe`, так в коде) |
| `background_color` | цветовой индикатор выбранного (цветной select) |
| `add_description` | подпись под полем |
| `hide`, `read_only` | состояние |
| `style` | инлайн-стиль |
| `regexp_rules` | валидация |
| `filter_on` | фильтр списка |

> В `edit_form` тип подменяется на `select` (оригинал — в `orig_type`).
> Бэкенд-логика (сохранение, фильтр) смотрит на `orig_type`.

## Примеры

```python
{'description': 'Тип отображения', 'type': 'select_values', 'name': 'type',
 'values': [
     {'v': '1', 'd': 'с вкладками'},
     {'v': '2', 'd': 'без вкладок'},
     {'v': '3', 'd': 'с фотогалереей'},
 ]}

# мультивыбор
{'description': 'Метки', 'type': 'select_values', 'name': 'tags',
 'values': [{'v': 'a', 'd': 'A'}, {'v': 'b', 'd': 'B'}], 'multilpe': 1}
```

## Особенности

- Подпись «выберите значение» добавляется на фронте в `edit_form` (в списке — нет).
- Для выбора из другой таблицы используйте
  [`select_from_table`](select_from_table.md).
- Если вариантов больше 15, контрол превращается в autocomplete.
