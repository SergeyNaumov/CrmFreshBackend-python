# База данных

## Классы

`db/__init__.py`:

- `FreshDB` (`db/freshdb.py`) — асинхронный, aiomysql. Рабочий.
- `FreshDBSync` (alias `FreshDB` из `db/freshdbs.py`) — синхронный, pymysql.
- `get_db(**arg)` — фабрика. `get_db(sync=1)` → sync, иначе async.
  `db` — **мемоизированный глобал**, не process-independent. В роутах
  используйте `request.state.engine.db` (или `form.db`), а не `get_db()`.

Пул создаётся в startup `main.py:39-41` (`await db.create_pool()`), настройки —
из `config['connects']['crm_write']`.

## `FreshDB` API

| Метод | Назначение |
|---|---|
| `query(query=..., values=[...], onerow/onevalue/massive/tree_use/str/debug)` | произвольный SQL |
| `get(**arg)` / `getrow(**arg)` | SELECT через `get_query` (собирает WHERE/JOIN/LIMIT) |
| `desc(table=...)` | описание таблицы, dict по `Field` |
| `save(table, data, update/where/replace/ignore/errors)` | INSERT/UPDATE/REPLACE |

- Обычный результат — список dict (DictCursor); `onerow=1` — один dict;
  `onevalue=1` — скаляр.
- `massive=1` → `massive_transform`; `tree_use=1` → дерево по `parent_id`
  (`db/functions.py`).
- `errors=[...]` — список, в который `out_error` допишет текст ошибки.
  Исключения наружу не пробрасываются (для `query` ловится `Exception` и идёт
  в `out_error`, возвращается `None`).

## Сборка SQL

SQL собирается **f-строками**: интерполируются имена таблиц и колонок,
параметризуются (`%s`) только значения. `where=` — сырой SQL по замыслу.
Значения вида `'func:now()'`, `'func:(NULL)'` подставляются в INSERT/UPDATE
дословно (`db/functions.py:get_func`, `freshdb.py:save`).

`get_query` (`db/functions.py:72`) собирает `select ... FROM wt [tables JOIN]`
`[WHERE] [ORDER] [LIMIT]` и считает `maxpage` для `perpage`.

## Известные дефекты

- `db/functions.py:116` — `query_count += " WHERE {where}"` без `f`: WHERE не
  попадает в count-запрос, ломается `maxpage`.
- `SET lc_time_names='ru_RU'` выполняется на **каждом** запросе
  (`db/freshdb.py:76`), плюс в `create_pool` — лишние round-trip.
- `db/freshdbs.py` дублирует `out_error`/`get_query`/`rez_to_str`/`get_func` из
  `db/functions.py`; `freshdbs.py:19` переопределяет `exists_arg`.
- `db.close_pool()` нигде не вызывается, shutdown-хука нет.

## Утилиты `lib/core.py`

- `exists_arg('key', data)` — идиома «получить или False», поддерживает
  вложенные пути `'a;b;c'`.
- `get_func(value)` — разбор `func:...`.
